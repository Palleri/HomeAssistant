## Agent skills

### Issue tracker

Issues are tracked in this repo's GitHub Issues (`Palleri/HomeAssistant`), managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the five default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: the glossary is `CONTEXT.md` and decisions are in `docs/adr/`, both at the repo root. See `docs/agents/domain.md`.
